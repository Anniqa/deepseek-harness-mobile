How it works

手机里跑着一个完整的 Harness

不依赖云端、不需要 root。dsh 本体运行在 App 自带的 Ubuntu 容器里，网页界面按手机触控重做。

1内置 Ubuntu 容器

proot 运行完整 Ubuntu 22.04（aarch64）rootfs 与 Node.js，容器内 dsh web 提供与桌面一致的能力。首次启动自动联网安装（中科大镜像源）。

2移动端适配 Web UI

注入式移动样式：覆盖式抽屉侧栏（左缘右滑呼出）、轨迹详情整宽覆盖、弹窗不溢出、触控目标加大、tooltip 自动消失。

3与手机互通

外置 SD 卡映射进容器工作区（sd/、shared/ 两个入口），文件双向传递；系统文件管理器直接上传附件。

Everything is a plugin

和桌面端同一个 Agent

模型所见的的一切都记录在只追加的会话日志里——提示词、推理、工具调用与结果、子代理调度，全部可在「轨迹」视图按来源检视。 四种模式与桌面端一致：

Standard

完整工具集：文件编辑、shell、文件/网络搜索、技能、规划、子代理、工作流

Code

以模型生成代码编排多轮工具调用，一个 TypeScript 程序组合多步操作

Minimal

仅持久 bash + 文件编辑器的双工具基准环境

Creator

检视运行时、内存中试验插件、编写自定义 Agent 预设

$ ssh dsh@127.0.0.1 -p 8022  # 本机终端直连容器
Get started

现在就装上

  • Android 8.0+，arm64 设备（约需 1GB 可用存储）
  • 安装 APK 后首启进入向导，联网下载容器组件（约 400MB，国内镜像）
  • 进入 Web 界面后按引导配置模型 API key 即可开始对话
  • 荣耀/MagicOS 用户：设置 → 后台保活，按引导开启两项授权
